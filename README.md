# Weald Feedback

Public issue tracker for [Weald](https://github.com/hunterh37), the native macOS mission control for agent-driven development.

Use this repo to report bugs and request features. The fastest path is the in-app reporter: **Weald > Settings > Feedback**, or press the feedback button in the Overwatch header. It opens a prefilled issue with your app version, macOS version, and hardware already filled in.

- [Report a bug](../../issues/new?template=bug.yml)
- [Request a feature](../../issues/new?template=feature.yml)

No source code lives here. Issues only.
